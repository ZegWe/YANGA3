# YANGA3
Yet Another NGA Android Application

## 诊断日志

从「我的 → 设置 → 关于 → 诊断日志」预览，之后可保存文本文件或通过 Android 系统分享菜单选择接收方。没有后台上传。日志保存在应用私有目录，定期按文件大小轮换；不记录账号、Cookie、完整网址、请求或响应正文、异常消息。用于同一次运行内关联的随机指纹不能跨重启比较。

- **崩溃**：重新打开应用再导出。日志包括未捕获 Java/Kotlin 异常的类型、堆栈与近期事件。Android 11 及以上也尽力记录系统报告的进程退出原因（例如 ANR、原生崩溃或系统终止），这些记录没有原生堆栈。未复现的崩溃不能从新版本还原。
- **乱码**：先在帖子右上角选「标记当前页乱码」，再刷新，不要先重启应用。恢复后导出，这样能对比同一次运行的请求字符集、刷新/缓存、正文和解析结果指纹、Compose 文本布局。统计和指纹是诊断线索，不会把乱码正文写入日志。
